# Composição do mob — Termos de uso e LGPD

Conversa: português (Brasil). Base: `ideation/scope-definition/scope-document.md`, `intent-backlog.md`, `ideation/feasibility/feasibility-assessment.md`, `constraint-register.md` e `team-formation-questions.md`.

Time de uma pessoa, sem mob humano (Q3). O "mob" de cada etapa é o responsável do projeto com os agentes de IA:

| Fase | Quem conduz | Quem apoia | Quem aprova |
|---|---|---|---|
| Ideação e Inception | Responsável do projeto | agentes de produto, arquitetura e entrega | Responsável do projeto |
| Construction | Responsável do projeto | agentes de desenvolvimento, qualidade e arquitetura (revisão) | Responsável do projeto |
| Revisão dos textos finais | Assessoria jurídica | — | Responsável do projeto |
| Operation | Responsável do projeto | agentes de operação e de plataforma | Responsável do projeto |

Sem parceiro externo além da assessoria jurídica (Q4). Um fuso só, no Brasil (Q3).
